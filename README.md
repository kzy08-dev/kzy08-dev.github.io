# Feral Gremlin To Do List - Client Project
Feral Gremlin is a to-do list app that serves the needs of a variety of user classes, specifically those with ADHD

## Description
This app acts as both a website and can be deployed on a mobile device as a Progressive Web Application (PWA). The purpose of the website is to enable its user to schedule various tasks to fit their schedule by allowing users to color code and prioritize what matters to them. In addition, it allows the user to block off periods of time that they are unavailable, schedule recurring events, pick music soundtracks to listen to while completing the events, and also take notes on the tasks. The app allows for users to login, which syncs their data across both their laptops and their mobile devices. Within the app, the user is able to earn virtual money for completing their tasks and care for their virtual pet, whose happiness is dependent on the user completing tasks. Overall, the combination of music, pets, and accessories is meant to generate a positive emotional response that allows the user to feel motivated to complete their tasks, making this a more effective version of a to-do list app.

## Features
- Calendar with customizable schedules
- Notetaking modals
- Music selector that allows upload of your own audio / Youtube links
- Virtual pet and balance
- Reward messages for completing tasks
- Options to prioritize and color code tasks
- Responsive layout to fit both mobile and desktop screens

## Installation
This website is deployed at: https://kzy08-dev.github.io
In order to use the website as a mobile app, click share for the website and add it to your home screen.
The app is deployed using Github pages and uses the development branch. For your own usage, clone the development branch, as that is the version being run.

## Technologies
This app runs using static HTML, CSS, and Javascript. It uses Firebase as a database to store user data.

## File Structure
Images, audio, and icons are organized within the assets subfolder. The sidebar and header HTML elements that are loaded on to every webpage excluding the login page are located within the components subfolder. CSS and Javascript files are located in their respective css and js folders. All of the HTML webpage files are located at the root level of the repository.
